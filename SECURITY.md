# Security Policy

## Scope

This project is a development foundation for tracking sensitive international tax structure information. It is not configured for production handling of taxpayer data.

## Reporting a vulnerability

Do not open a public GitHub issue for a suspected security vulnerability. Report it privately to the repository maintainer using the security contact configured in the GitHub repository.

Include:

- affected component and version/commit
- reproducible steps or proof of concept
- security impact
- any suggested mitigation

Do not include real taxpayer identifiers, credentials, tax documents or other confidential data in the report.
